### 简单示例

输入表格：

```html
<table>
  <tr>
    <th rowspan="2">样品号</th>
    <th rowspan="2">岩性</th>
    <th colspan="2">孔隙结构</th>
  </tr>
  <tr>
    <th>孔隙度/%</th>
    <th>渗透率/mD</th>
  </tr>
  <tr>
    <td>FY1-1</td>
    <td>砂岩</td>
    <td>5.1</td>
    <td>0.12</td>
  </tr>
</table>
```

1. 输入适配

`adapt_table_chunk()` 将 Stage-02 的表格数据转换为 `TableSource`。如果输入是 HTML，就直接进入 HTML 解析；如果输入是图片，则使用 RapidOCR + RapidTable 识别 HTML，必要时回退 MinerU。

对应代码：[table_parse.py:111](C:/Users/nzx/Desktop/Python/毕业论文项目/MulTreeMMKG/src/extractors/table_extractor/table_parse.py:111)、[table_parse.py:1590](C:/Users/nzx/Desktop/Python/毕业论文项目/MulTreeMMKG/src/extractors/table_extractor/table_parse.py:1590)。

2. HTML 规范化

`canonicalize_html()` 使用 BeautifulSoup 清理无关标签，保留 `table`、`tr`、`th`、`td` 以及 `rowspan`、`colspan` 等结构信息。

示例中的合并表头会被规范化为稳定的 HTML。对应代码：[table_parse.py:230](C:/Users/nzx/Desktop/Python/毕业论文项目/MulTreeMMKG/src/extractors/table_extractor/table_parse.py:230)。

3. 展开为二维网格

`parse_html_table()` 根据逻辑坐标展开合并单元格：

```text
[
  ["样品号", "岩性", "孔隙结构",       "孔隙结构"],
  ["样品号", "岩性", "孔隙度/%",       "渗透率/mD"],
  ["FY1-1",  "砂岩", "5.1",            "0.12"]
]
```

其中：

```text
header_rows = [0, 1]
orientation = "horizontal"
```

原始单元格仍保留：

```text
样品号：rowspan=2
岩性：rowspan=2
孔隙结构：colspan=2
```

对应代码：[table_parse.py:312](C:/Users/nzx/Desktop/Python/毕业论文项目/MulTreeMMKG/src/extractors/table_extractor/table_parse.py:312)。

4. 构造完整字段路径

多级表头会组合成字段路径：

```text
[
  "样品号",
  "岩性",
  "孔隙结构 / 孔隙度/%",
  "孔隙结构 / 渗透率/mD"
]
```

这样可以避免只保存“孔隙度”而丢失它属于“孔隙结构”的层级信息。对应代码：[table_parse.py:495](C:/Users/nzx/Desktop/Python/毕业论文项目/MulTreeMMKG/src/extractors/table_extractor/table_parse.py:495)。

5. 质量门禁

模块会检查：

- 表格是否为空；
- 单元格非空比例；
- OCR 内容覆盖率；
- 行列坐标是否一致；
- 表尾是否出现连续缺列。

质量不合格时，任务会标记为 `manual_review`，不会继续生成知识图谱。对应代码：[table_parse.py:571](C:/Users/nzx/Desktop/Python/毕业论文项目/MulTreeMMKG/src/extractors/table_extractor/table_parse.py:571)。

6. 确定主键和语义

`infer_semantic_plan()` 判断这是横向表：

```json
{
  "orientation": "horizontal",
  "data_start_row": 2,
  "subject_column": 0,
  "subject_type": "Sample"
}
```

因为第一列是“样品号”，所以数据行：

```text
FY1-1
```

被识别为一个 `Sample` 实体。数值 `5.1` 和 `0.12` 则分别关联到“孔隙度”和“渗透率”参数。对应代码：[table_extractor.py:124](C:/Users/nzx/Desktop/Python/毕业论文项目/MulTreeMMKG/src/extractors/table_extractor/table_extractor.py:124)。

7. 生成图谱

图谱中会生成结构节点：

```text
Table
TableHeader
TableRow
TableColumn
TableCell
Parameter
```

同时生成领域节点：

```text
Sample: FY1-1
Lithology: 砂岩
```

典型关系包括：

```text
Table --HAS_ROW--> TableRow
Table --HAS_COLUMN--> TableColumn
TableCell --LOCATED_IN_ROW--> TableRow
TableCell --LOCATED_IN_COLUMN--> TableColumn
TableColumn --REPRESENTS--> Parameter
Table --REPORTS--> Sample
Sample --RECORDED_IN--> Table
Sample --COLLECTED_FROM--> Lithology
```

最终由 `build_table_graph()` 完成结构图和领域语义图装配，并进行 Schema 校验。对应代码：[table_extractor.py:746](C:/Users/nzx/Desktop/Python/毕业论文项目/MulTreeMMKG/src/extractors/table_extractor/table_extractor.py:746)。

简单概括：这个模块不是直接把 OCR 文本拼成实体，而是先将表格恢复为“规范 HTML → 逻辑二维网格 → 完整字段路径 → 主键语义 → Schema 约束图谱”。
