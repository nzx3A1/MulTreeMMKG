# 运行结果

批量入口会在此目录生成：

- `two_dimensional_stratigraphic_log_live_batch_results.json`：逐图原始响应审计、中间结果、Graph 与质量校验。
- `two_dimensional_stratigraphic_log_live_batch_nodes.json`：所有完成图片的实体节点。
- `two_dimensional_stratigraphic_log_live_batch_relations.json`：所有完成图片的实体关系。

结果只覆盖源清单中 `stratigraphic_subtype.subtype=two_dimensional_stratigraphic_log` 的图片。
