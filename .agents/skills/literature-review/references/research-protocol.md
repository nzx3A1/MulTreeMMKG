# 检索与证据协议

## 检索记录

每次检索至少记录：

- `source`：数据库或网站名称
- `query`：实际提交的完整检索式
- `searched_at`：带时区的检索日期时间
- `filters`：年份、语言、文献类型等过滤条件
- `result_count`：数据库报告或本次实际获取的数量
- `notes`：访问限制、分页截断和覆盖范围

概念组内用 OR，概念组间用 AND。先用宽检索识别领域术语，再收紧检索式；不要只保留最后一次检索记录。

## 去重优先级

1. DOI：去除 `https://doi.org/`、`doi:`、空格和末尾标点后转为小写。
2. 其他稳定标识：PMID、arXiv ID、OpenAlex ID、DBLP key。
3. 规范化标题 + 年份 + 第一作者。标题比较时统一大小写、空白和常见标点，但保留原始题名字段。
4. 预印本与正式版不直接删除；用 `version_of` 关联，并优先引用最终出版版。

## 筛选记录

标题摘要筛选和全文筛选分开记录。常用排除理由包括：主题不相关、研究对象不符、方法信息不足、非目标文献类型、重复记录、无法获得必要正文、撤稿或更正后失效。每篇文献只记录一个主要排除理由，便于统计。

## 证据等级

- `full_text`：已阅读可定位的全文，记录页码、章节、表格或图号。
- `abstract_only`：只验证摘要，不得写入摘要未支持的技术细节或数值。
- `metadata_only`：只验证题名、作者、年份、来源、DOI 等元数据。
- `secondary`：信息来自综述或其他二手来源，必须标明且尽可能回溯原论文。
- `inference`：分析者根据多项来源做出的推断，必须使用“推断”“可能”等明确措辞。

## 事实核验

- 作者、年份、期刊和 DOI 至少使用 Crossref、出版社或论文首页中的一个权威来源核对。
- 实验数字必须定位到原文表格、正文或补充材料；记录指标方向、数据集和实验条件。
- 搜索结果片段不能作为最终证据。
- 元数据冲突时保留冲突字段和来源，不擅自选择看似合理的值。
- 撤稿、勘误和版本更新属于可能变化的信息，交付前应在线复核。

## 综述结构

优先使用“问题背景 → 方法谱系 → 数据与评价 → 主要共识和冲突 → 局限性 → 研究空白 → 与本项目关系”的结构。研究空白必须来自已检索证据的覆盖情况，不能仅用“研究较少”等泛化表述。
