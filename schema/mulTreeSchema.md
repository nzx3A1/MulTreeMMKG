
### 5.1 地理与构造单元

| Schema | 中文类型 | 专业定义 | 典型实例或识别线索 |
|---|---|---|---|
| `Basin` | 盆地 | 具有相对独立沉积、构造演化和油气成藏背景的大型地质空间单元，是石油地质研究中的核心区域实体。 | 鄂尔多斯盆地；四川盆地；塔里木盆地 |
| `StructuralUnit` | 构造单元 | 盆地内部按照构造形态、构造位置或构造演化特征划分出的次级地质单元。 | 伊陕斜坡；天环坳陷；中央隆起带 |
| `Depression` | 凹陷/坳陷 | 相对于周缘构造位置较低、沉积厚度较大、常为烃源岩发育有利区的负向构造单元。 | 济阳坳陷；黄骅坳陷；天环坳陷 |
| `Sag` | 洼陷 | 通常指坳陷内部更局部、更低洼的沉积中心或构造低部位，是细粒沉积和烃源岩发育的重要区域。 | 渤南洼陷；苏桥洼陷；辽中洼陷 |
| `Uplift` | 隆起 | 相对于周边地区构造位置较高的正向构造单元，常控制地层剥蚀、圈闭形成和油气运移方向。 | 伊盟隆起；渤中隆起；塔中隆起 |
| `Slope` | 斜坡 | 位于隆起与坳陷之间的倾斜过渡带，常是砂体展布、油气运移和岩性圈闭发育的重要区域。 | 伊陕斜坡；北部斜坡带；南部斜坡区 |
| `StructuralBelt` | 构造带 | 由一组具有相似构造变形特征的构造要素组成的带状区域，如逆冲带、褶皱带、断裂构造带等。 | 西缘逆冲带；贺兰－六盘山构造带；断裂构造带 |
| `Fault` | 断层 | 岩层或地质体沿破裂面发生明显位移形成的构造实体，可影响地层展布、油气运移和圈闭形成。 | F1断层；郯庐断裂；正断层 |
| `FaultZone` | 断裂带 | 由多条断层及其相关破碎带、裂缝带共同组成的带状构造区域，常作为油气运移通道或封堵边界。 | 郯庐断裂带；贺兰－六盘山断裂带；边界断裂带 |
| `Block` | 区块 | 油气勘探开发中按照地理位置、构造位置或开发管理需要划分的研究或开发单元。 | 苏里格区块；塔中区块；长庆油田某开发区块 |
| `StudyArea` | 研究区 | 论文、报告或项目中限定的具体研究范围，可以是盆地、凹陷、区块、剖面或井区。 | 鄂尔多斯盆地东南部研究区；川东北研究区；塔里木盆地塔中地区 |

### 5.2 地层与地质时代

| Schema | 中文类型 | 专业定义 | 典型实例或识别线索 |
|---|---|---|---|
| `GeologicAge` | 地质时代 | 表示地层形成或地质事件发生的时间单位，可包括宙、代、纪、世、期等不同层级。 | 三叠纪；侏罗纪；寒武纪 |
| `Formation` | 组 | 岩石地层单位中的基本单位，通常具有相对稳定的岩性组合和区域可识别性。 | 延长组；马家沟组；龙马溪组 |
| `StratigraphicMember` | 段 | 组以下的次一级地层单位，常用于进一步划分储层、烃源岩或沉积旋回。 | 长7段；长8段；马五段 |
| `SubMember` | 亚段/小层 | 段以下更精细的地层划分单元，常用于储层精细对比和小层划分。 | 长7三亚段；马五5小层；长6一小层 |
| `Bed` | 层/单层 | 最基本的层状地质单元，通常对应一个单独的岩层、砂层、泥岩层或煤层。 | 单砂层；泥岩层；7号煤层 |
| `ReservoirInterval` | 目的层/储层段 | 勘探开发或储层评价中重点研究的含油气层段或目标储层层位。 | 长7储层段；马五目的层；盒8储层段 |
| `StratigraphicBoundary` | 地层界面 | 不同地层单元之间的分界面，可反映沉积间断、岩性变化或地质时代转换。 | 奥陶系顶界面；延长组底界面；组段分界面 |
| `Unconformity` | 不整合面 | 上下两套地层之间存在沉积间断、剥蚀或构造变形差异的地层接触界面。 | 加里东不整合面；印支期不整合面；区域不整合面 |
| `SequenceStratigraphicUnit` | 层序单元 | 层序地层学中依据基准面变化、沉积旋回和界面特征划分出的地层单元。 | 三级层序；SQ1；SQ2 |
| `SequenceBoundary` | 层序界面 | 层序单元之间的边界，通常与相对湖平面或海平面变化、沉积间断或侵蚀面有关。 | SB1；SB2；三级层序界面 |
| `SystemTract` | 体系域 | 层序内部根据沉积充填样式和基准面变化阶段划分的沉积组合单元。 | 低位体系域；湖侵体系域；高位体系域 |

### 5.3 岩石、矿物与沉积体系

| Schema | 中文类型 | 专业定义 | 典型实例或识别线索 |
|---|---|---|---|
| `Lithology` | 岩性 | 岩石类型及其基本物质组成特征，是描述地层、储层和沉积环境的重要实体。 | 砂岩；泥岩；灰岩；白云岩 |
| `Mineral` | 矿物 | 组成岩石的基本矿物成分，可影响储层物性、成岩作用和脆性特征。 | 石英；长石；方解石；黏土矿物 |
| `RockTexture` | 岩石结构/组构 | 岩石中颗粒、晶体或组分的大小、形态、排列和接触关系等结构特征。 | 粒状结构；泥晶结构；交代结构；碎屑结构 |
| `SedimentaryStructure` | 沉积构造 | 沉积过程中形成的层理、波痕、冲刷面等构造现象，可用于判断沉积环境和水动力条件。 | 交错层理；水平层理；波痕；冲刷面 |
| `SedimentaryFacies` | 沉积相 | 在一定沉积环境下形成的岩性、结构、构造和古生物特征组合。 | 三角洲相；湖泊相；河流相；碳酸盐台地相 |
| `Subfacies` | 亚相 | 沉积相内部的次一级划分，用于更精细描述沉积环境和砂体分布。 | 三角洲前缘亚相；滨浅湖亚相；半深湖亚相 |
| `Microfacies` | 微相 | 亚相内部更精细的沉积单元，常用于储层非均质性分析和砂体精细刻画。 | 水下分流河道微相；河口坝微相；席状砂微相 |
| `DepositionalEnvironment` | 沉积环境 | 沉积物形成时的自然环境条件，包括水体类型、能量条件、气候背景和构造背景等。 | 浅湖环境；半深湖环境；滨浅海环境；三角洲前缘环境 |
| `DepositionalSystem` | 沉积体系 | 由若干相关沉积相、亚相和微相组成的沉积组合系统，反映区域沉积过程和沉积格局。 | 三角洲沉积体系；扇三角洲沉积体系；浊积扇沉积体系 |
| `Diagenesis` | 成岩作用 | 沉积物埋藏后到变质作用前经历的物理、化学和生物改造过程。 | 压实作用；胶结作用；溶蚀作用；交代作用 |
| `DiageneticStage` | 成岩阶段 | 根据埋藏深度、温度、成岩矿物和孔隙演化特征划分的成岩演化时期。 | 早成岩A期；早成岩B期；中成岩A期 |
| `DiageneticFacies` | 成岩相 | 由特定成岩作用、成岩矿物组合和孔隙演化特征共同表征的成岩类型单元。 | 溶蚀相；碳酸盐胶结相；压实致密相 |

### 5.4 油气成藏要素

| Schema | 中文类型 | 专业定义 | 典型实例或识别线索 |
|---|---|---|---|
| `PetroleumSystem` | 含油气系统/成藏系统 | 由烃源岩、储层、盖层、圈闭、运移和保存条件等共同构成的油气生成、运移与聚集系统。 | 鄂尔多斯盆地延长组成藏系统；四川盆地下古生界含气系统 |
| `SourceRock` | 烃源岩 | 富含有机质并能够生成油气的岩石，是油气成藏的物质基础。 | 长7烃源岩；龙马溪组页岩；湖相泥页岩 |
| `Reservoir` | 储层/储集层 | 具有一定孔隙、裂缝或洞穴空间，能够储集和渗流油气的岩层。 | 长6砂岩储层；马五碳酸盐岩储层；页岩储层 |
| `Seal` | 盖层 | 覆盖在储层之上或周围、能够阻止油气逸散的低渗透性岩层。 | 泥岩盖层；膏盐岩盖层；致密灰岩盖层 |
| `Trap` | 圈闭 | 能够阻止油气继续运移并使油气聚集保存的地质空间结构。 | 构造圈闭；岩性圈闭；地层圈闭；复合圈闭 |
| `MigrationPathway` | 运移通道 | 油气从烃源岩向储层或圈闭运移过程中经过的通道或介质。 | 断层运移通道；砂体输导层；裂缝通道 |
| `CarrierSystem` | 输导体系 | 由断层、裂缝、砂体、不整合面等共同组成的油气输导网络。 | 断砂组合输导体系；裂缝输导体系；不整合面输导体系 |
| `AccumulationProcess` | 成藏过程 | 油气从生成、排出、运移、聚集到保存的动态地质过程。 | 生烃；排烃；油气运移；油气聚集 |
