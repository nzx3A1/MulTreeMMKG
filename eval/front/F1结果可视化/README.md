# 文本抽取 F1 结果可视化

在仓库根目录运行：

```powershell
python eval/front/F1结果可视化/server.py
```

打开 <http://127.0.0.1:8767>。如需换端口，传入 `--port 端口号`。

页面实时读取 `eval/抽取评测/F1计算/text_f1_report.json`，展示总体 Micro 指标、逐 Chunk 指标与严格匹配的 FP/FN 差异。可切换严格/归一化匹配、按文档筛选及搜索 Chunk ID。点击“刷新数据”会重新读取报告文件。

报告使用未经人工复核的参考标注。页面分数表示与当前参考文件的一致程度，不代表专家金标准准确率。差异明细来自报告中的 `strict_differences`，即使切换到归一化指标也仍显示严格匹配差异。
