下面这套方案可直接作为论文“实验设计与评测方法”章节的主体。核心不是只评价最终图谱，而是建立一条可追责的证据链：

**单模态抽取是否正确 → 融合是否正确 → 最终图谱是否可信 → 图谱是否真正改善下游任务。**

VAT-KG 的评测包括中间阶段人工正确性、最终三元组质量、不同知识图谱下的问答对比、模态消融、检索校验消融以及多次重复试验。你的方案可以继承这一结构，但需要增加更细的实体/关系抽取指标、聚类指标、Schema 一致性和来源可追溯性指标。[VAT-KG 论文](https://arxiv.org/html/2506.21556v3)

## 一、评测数据集构建

### 1. 数据来源与规模

建议构建一个“地质文档多模态知识图谱评测集”，以完整文档为基本划分单位，而不是随机拆分 Chunk。

推荐的硕士论文规模：

| 数据子集 | 文档数 | 用途 |
|---|---:|---|
| 构建集 | 36 | 提示词设计、规则设计、少样本示例 |
| 验证集 | 12 | 阈值选择、模型选择、消融调试 |
| 测试集 | 12 | 只用于最终报告 |
| 合计 | 60 | 文档级 6:2:2 划分 |

其中至少选择30篇进行完整金标准标注，建议覆盖：

- 100个文本 Chunk；
- 100个图像 Chunk；
- 100个表格 Chunk；
- 600组跨模态实体判同候选；
- 200～300条最终图谱三元组；
- 250个下游问答样本。

如果标注预算有限，可以把剩余文档作为银标数据，但验证集和测试集必须是专家人工标注的金标准。

### 2. 文档分层采样

需要控制以下分布，避免测试集只包含简单论文：

- 领域：盆地、层序地层、沉积相、储层、油气成藏、测井等；
- 文档类型：期刊论文、学位论文、地质报告；
- 图像类型：地质图、剖面图、柱状图、测井曲线、统计图、岩心或薄片照片；
- 表格类型：属性表、对比表、实验数据表、地层划分表；
- 难度：清晰、一般、模糊或复杂；
- 跨模态程度：单模态即可回答、需要两种模态、需要三种模态。

相同论文的不同版本、同一区域高度重复的文档不能跨训练集和测试集，以防信息泄漏。

### 3. 分层标注结构

不要直接只标最终三元组。建议建立六层金标准：

1. **源证据层**  
   标注文档、章节、Chunk、页码、模态和原始内容。

2. **单模态提及层**  
   标注实体边界、实体类型、属性、关系、事件和限定信息。

3. **证据定位层**  
   文本记录字符区间；图像记录框、图例项或区域；表格记录行、列、单元格。

4. **Schema 对齐层**  
   标注目标实体类型、关系类型、对齐状态以及无法映射项。

5. **跨模态融合层**  
   标注哪些提及属于同一真实实体，形成金标准实体簇；同时保留 `SAME`、`DIFFERENT`、`UNCERTAIN`。

6. **最终图谱层**  
   标注融合后的全局实体、关系、限定条件、冲突和全部来源证据。

实体提及的唯一身份应使用：

\[
(document\_id,\ chunk\_id,\ original\_entity\_id)
\]

不能只用实体名称或局部 ID。尤其要加入“同名不同井”“同名不同地层”“岩性大类与子类”“包含关系两端”等困难负例。

### 4. 下游问答集

推荐构建250题：

| 问题类型 | 数量 | 示例能力 |
|---|---:|---|
| 单跳事实问答 | 50 | 某地层岩性是什么 |
| 跨模态问答 | 50 | 正文和剖面图共同支持的结论 |
| 多跳关系推理 | 50 | 地层→岩性→储集性 |
| 表格数值问答 | 40 | 孔隙度、深度、厚度、单位换算 |
| 综合归纳问答 | 40 | 对比不同井或不同层段 |
| 不可回答问题 | 20 | 检验拒答与幻觉 |

每个问题必须同时标注：

- 标准答案；
- 可接受别名；
- 支持答案的 Chunk；
- 支持实体和关系；
- 最小证据路径；
- 是否必须使用图像或表格；
- 是否不可回答。

### 5. 标注质量控制

- 两名地质专业标注者独立标注；
- 第三名专家仲裁分歧；
- 先用10%的样本试标并完善规范；
- 实体类型和关系类型报告 Cohen’s κ；
- 三人以上使用 Fleiss’ κ；
- 目标：实体/类型 κ≥0.80，关系和融合判定 κ≥0.75；
- 来源材料本身含糊时标为 `UNCERTAIN`，不能强制生成确定答案。

# 二、单模态抽取评测

文本、图像、表格必须分别测试，不能把所有结果合并后只报告一个总 F1。

## 1. 文本抽取

主要指标：

- 实体识别：严格匹配 Precision、Recall、F1；
- 实体宽松匹配：边界部分重合或规范名一致；
- 实体类型准确率、Macro-F1；
- 属性抽取 F1；
- 关系三元组 Precision、Recall、F1；
- 关系方向准确率；
- 事件触发词和事件论元 F1；
- 证据跨度准确率；
- 幻觉率：输出中无法被原文支持的实体或关系占比。

关系只有在“头实体、关系类型、尾实体、方向、限定条件”均正确时，才计为严格正确。

## 2. 图像抽取

除实体和关系 F1 外，按图像类型分别报告：

- 图像分类准确率和 Macro-F1；
- 图例识别准确率；
- 标注文字或 OCR 字符准确率；
- 地层、井、岩性、构造等实体 F1；
- 空间关系 F1；
- 图例符号—地质概念绑定准确率；
- 深度、坐标、比例尺和单位准确率；
- 图像证据定位 IoU 或区域命中率；
- 图像事实支持率与幻觉率。

地质图、剖面图、测井图、普通统计图应分别报告结果，不能只报告总体平均值。

## 3. 表格抽取

主要指标：

- 表头识别准确率；
- 行列结构恢复准确率；
- 实体、属性和值抽取 F1；
- 数值 Exact Match；
- 允许容差的数值准确率，例如相对误差≤1%；
- 单位识别和单位归一化准确率；
- 表头—数据单元格关联准确率；
- 跨行、跨列关系三元组 F1；
- 空值保持率，避免把空单元格臆造为数值。

## 4. 单模态对比方法

建议统一使用相同模型版本、温度和推理预算，比较：

| 编号 | 方法 |
|---|---|
| E0 | 通用 LLM/VLM 直接零样本抽取 |
| E1 | 通用模型＋少样本示例 |
| E2 | 通用模型＋地质 Schema 约束 |
| E3 | OCR/图像描述/表格序列化后统一文本抽取 |
| E4 | 你的模态分类＋专用路由＋Schema 约束完整方法 |

论文主表需要分别列出 Text、Image、Table 的实体 F1、关系 F1、证据准确率和幻觉率。

# 三、多模态融合评测

这一部分要把“候选召回”“实体判同”“实体聚类”“关系融合”分开评价。

## 1. 候选生成

衡量正确实体对是否进入候选集合：

- Candidate Recall@K；
- 候选压缩率；
- 每个实体平均候选数；
- 困难正例召回率；
- 困难负例比例。

候选召回率是融合系统的上限。如果正确实体对没有被召回，后面的 LLM 或规则无法补救。

## 2. 实体对判定

对 `SAME/DIFFERENT/UNCERTAIN` 计算：

- SAME 类 Precision、Recall、F1；
- Macro-F1；
- PR-AUC；
- 混淆矩阵；
- 自动融合覆盖率；
- 在不同覆盖率下的错误率；
- 转人工复核比例。

融合错误需要分成：

- **过度融合**：不同井、不同地层或父子概念被合并；
- **融合不足**：同一实体跨文本、图像、表格仍然分裂；
- **传递性错误**：A=B、B=C 后错误地得到 A=C；
- **作用域错误**：局部坐标轴、图例、数据序列被跨 Chunk 合并。

## 3. 实体聚类

仅评价实体对还不够，需要评价最终实体簇：

- Pairwise Precision、Recall、F1；
- B³ Precision、Recall、F1；
- MUC；
- CEAF-e；
- 过度融合簇比例；
- 融合不足簇比例；
- 完全正确实体簇比例。

B³ F1 建议作为实体融合的主指标，因为它同时反映过度融合和融合不足。

结果还应分别按模态组合报告：

- Text–Image；
- Text–Table；
- Image–Table；
- Text–Image–Table。

## 4. 关系融合

评价内容包括：

- 关系端点重写准确率；
- 关系去重 Precision、Recall、F1；
- 关系方向保持率；
- 限定条件保持率；
- 多来源证据聚合完整率；
- 自环关系判断准确率；
- 跨模态关系融合 F1；
- 源关系统计守恒率；
- 悬空端点数量。

特别要检查：实体融合后，原始关系是否全部迁移到新的全局实体上，而不是丢失或连接到错误节点。

## 5. 来源与冲突保存

建议设置工程正确性硬指标：

- 实体提及保存率应为100%；
- 关系证据保存率应为100%；
- `document_id/chunk_id/modality/original_id` 完整率应为100%；
- 悬空关系端点应为0；
- Schema 未映射项不得被静默丢弃；
- 相同输入重复运行的结果哈希应一致；
- 冲突检测 Precision、Recall、F1。

你当前的真实输出中，571个源实体提及融合为394个全局实体，966条源关系形成910条全局关系，且没有悬空端点；这些只能作为**流程守恒和工程基线**，不能代替人工准确率。[当前 Stage 06 输出](/C:/Users/nzx/Desktop/Python/毕业论文项目/MulTreeMMKG/output/stage_06_multimodal_aligned_graph.json)

## 6. 融合对比方法

| 编号 | 方法 |
|---|---|
| F0 | 不融合，直接合并三个模态的图 |
| F1 | 规范化名称完全相同才融合 |
| F2 | 编辑距离或字符串相似度融合 |
| F3 | 仅 Embedding 阈值融合 |
| F4 | LLM 两两判同 |
| F5 | 名称＋类型＋属性＋上下文＋Embedding |
| F6 | 你的完整方法：候选召回＋规则/Embedding/LLM＋聚类硬约束＋关系重写 |

# 四、最终图谱质量评测

最终图谱质量不能只用节点数、边数和密度衡量。建议分为六个维度。

## 1. 正确性

- 实体准确率；
- 类型准确率；
- 属性准确率；
- 三元组准确率；
- 限定条件准确率；
- 证据支持率；
- 图文表内容一致性。

## 2. 完整性

在金标准图谱上计算：

- 实体召回率；
- 关系召回率；
- 属性召回率；
- Schema 类型覆盖率；
- 跨模态事实召回率；
- 关键地质概念覆盖率。

## 3. 一致性

- Schema domain/range 违反率；
- 互斥类型冲突率；
- 单位冲突率；
- 关系方向冲突率；
- 同一实体属性冲突率；
- 井号、层位、深度等标识冲突率；
- 无效自环率；
- 重复实体率和重复关系率。

## 4. 可追溯性

- 有来源实体比例；
- 有来源关系比例；
- 可回溯到原始 Chunk 的比例；
- 可回溯到文本跨度、图像区域或表格单元格的比例；
- 多来源事实证据完整率；
- 冲突是否保留原始证据。

## 5. 覆盖度与多模态贡献

- 文本、图像、表格贡献的独有实体数；
- 各模态独有关系数；
- 跨模态实体比例；
- 跨模态关系比例；
- 加入图像或表格后新增的正确知识量；
- 各 Schema 类型的实体和关系覆盖分布。

## 6. 人工质量评估

VAT-KG 从中间阶段各抽取50个样本，并对最终30条三元组评价概念准确性、内容捕获忠实度和描述对齐度。[VAT-KG 人工评测](https://arxiv.org/html/2506.21556v3#A4)

你的评测建议扩展到至少200条分层抽样三元组，由地质专家按五个维度打分：

1. 实体或概念是否真实出现；
2. 关系是否符合原始材料；
3. 是否捕获材料的核心语义；
4. Schema 类型和关系是否恰当；
5. 来源证据是否足以支持该事实。

采用0～2三级评分：

- 0：错误；
- 1：部分正确或证据不足；
- 2：完全正确。

报告平均分、完全正确率、95%置信区间和标注者一致性。

# 五、下游可用性评测

推荐以“地质文档知识问答/Graph-RAG”为主任务，同时评价检索和答案生成。

## 1. 对比系统

为了证明提升来自图谱，而不是模型变化，生成模型、提示词和检索预算必须保持一致。

| 编号 | 下游方法 |
|---|---|
| D0 | 闭卷 LLM，不提供外部知识 |
| D1 | 文本向量 RAG |
| D2 | 文本＋图像＋表格多模态向量 RAG |
| D3 | 仅文本抽取的 KG-RAG |
| D4 | 三种单模态图简单拼接，不进行融合 |
| D5 | 你的完整多模态融合 KG-RAG |
| D6 | Oracle：直接提供人工标注证据，作为性能上限 |

VAT-KG 采用了“无知识图谱、Wikidata、VTKG、M²ConceptBase、VAT-KG”的横向对比。对你的地质任务而言，直接比较通用 VAT-KG 意义不大，更合理的是使用上述同源语料、同一生成模型的内部受控基线。[VAT-KG 实验设置](https://arxiv.org/html/2506.21556v3#S5)

## 2. 检索指标

- Hit@K；
- Recall@K；
- Precision@K；
- MRR；
- nDCG@K；
- 正确实体召回率；
- 正确三元组召回率；
- 金标准证据路径召回率；
- 跨模态证据召回率。

## 3. 答案指标

封闭式或短答案：

- Exact Match；
- Token-F1；
- 数值准确率；
- 单位准确率。

开放式答案：

- 事实正确性；
- 答案完整性；
- 与问题相关性；
- 推理合理性；
- 证据忠实性；
- 引用准确率；
- 幻觉率。

开放式答案可以使用 Model-as-Judge，但裁判提示中必须提供标准答案和金标准证据，并对系统名称匿名、随机打乱顺序。

## 4. 人工评估

随机抽取20%的问答结果，由专家按0～5分评价：

- Correctness；
- Completeness；
- Relevance；
- Faithfulness；
- Professionalism。

同时记录：

- 是否存在无证据断言；
- 是否引用错误模态；
- 是否错误合并不同井或不同地层；
- 是否应拒答而未拒答。

## 5. 效率和实用性

除效果外还需要报告：

- 单文档构图耗时；
- 单 Chunk 抽取耗时；
- LLM/VLM 调用次数；
- Token 或 API 成本；
- 图谱存储规模；
- 单次查询延迟；
- 检索和生成总耗时；
- 需要人工复核的候选比例。

# 六、消融实验设计

## 1. 单模态抽取消融

| 消融项 | 验证目标 |
|---|---|
| 去除 Schema 约束 | Schema 对类型和关系规范化的作用 |
| 去除章节及相邻 Chunk 上下文 | 文档层次上下文的作用 |
| 去除图像类型专用路由 | 地质图、剖面图等专用抽取的作用 |
| 去除图例解析 | 图例语义绑定的作用 |
| 去除确定性空间关系构建 | 程序规则对空间关系可靠性的作用 |
| 表格转纯文本 | 表格结构信息的作用 |

## 2. 多模态融合消融

| 消融项 | 验证目标 |
|---|---|
| 仅名称 | 最简单基线 |
| 去除类型兼容约束 | 类型约束防止错误融合的作用 |
| 去除属性信息 | 井号、地层、深度等标识属性的作用 |
| 去除上下文 | 局部语境的作用 |
| 去除邻接结构 | 图结构证据的作用 |
| 去除 Embedding | 语义召回的作用 |
| 去除 LLM 灰区判断 | LLM 对模糊候选的作用 |
| 去除簇级硬约束复查 | 防止传递性过度融合的作用 |
| 去除关系证据聚合 | 来源保持对最终图谱的作用 |

最重要的指标是 B³ F1、过度融合率、关系融合 F1 和下游 QA 变化。

## 3. 模态贡献消融

至少比较：

- Text；
- Image；
- Table；
- Text+Image；
- Text+Table；
- Image+Table；
- Text+Image+Table。

这样才能证明“多模态融合”优于“数据量增加”，并判断图像和表格分别带来了什么知识。

## 4. 下游消融

- 无图谱；
- 有图谱但不融合；
- 融合实体、不融合关系；
- 实体＋关系完整融合；
- 去除证据来源；
- 去除检索重排或检索校验；
- 只检索一跳；
- 检索多跳子图；
- 不同 Top-K；
- 不同融合阈值。

VAT-KG 的主要消融包括单模态与联合模态检索，以及是否使用 Retrieval Checker；你的“证据重排/校验模块”也应采用相同的开关式实验。[VAT-KG 消融实验](https://arxiv.org/html/2506.21556v3#A5.SS1)

# 七、统计检验与报告规范

建议采用以下统一实验协议：

- LLM/VLM 非确定性实验独立运行5次；
- Model-as-Judge 可运行10次；
- 以文档或问题为单位做配对比较；
- 使用文档级 Bootstrap 计算95%置信区间；
- 正确/错误型结果采用 McNemar 检验；
- 连续得分采用配对 t 检验或 Wilcoxon 检验；
- 显著性阈值设为 \(p<0.05\)；
- 多组比较采用 Holm 校正；
- 除 p 值外报告绝对增益和效应量。

VAT-KG 进行了10次独立裁判试验并报告标准差和 t 检验；你的实验最好采用更严格的 \(p<0.05\)，同时加入文档级 Bootstrap。[VAT-KG 统计验证](https://arxiv.org/html/2506.21556v3#A5.SS4)

# 八、论文中建议呈现的核心表格

1. 数据集文档、Chunk、实体、关系和模态统计；
2. 标注一致性统计；
3. 文本/图像/表格单模态抽取结果；
4. 各图像类型和表格类型的细分结果；
5. 跨模态实体匹配与聚类结果；
6. 关系融合和来源保存结果；
7. 最终图谱正确性、完整性、一致性和可追溯性；
8. 不同知识源下的下游 QA 结果；
9. 单模态与模态组合消融；
10. 融合组件消融；
11. 效率、成本和人工复核量；
12. 典型成功案例和失败案例。

最终建议选取四个主指标作为全文主线：

- 单模态抽取：**Macro-F1**；
- 多模态融合：**B³ F1**；
- 最终图谱：**证据支持的严格三元组 F1**；
- 下游可用性：**完整图谱相对无图谱的 QA 增益及证据忠实度**。

不要把所有维度任意加权成一个“图谱总分”。分维度报告更容易说明问题，也更符合知识图谱评测的可信性要求。
