可以把完整方案压缩成一个“16篇文档、120个Chunk、60道问答”的MVP。这个规模能够贯通四个评测阶段，也足以支撑硕士论文的首轮实验和消融分析。

## 一、MVP数据集

### 1. 文档选择

选择16篇地质文档：

- 4篇开发集：调整提示词、规则和融合阈值；
- 12篇测试集：参数冻结后一次性评测；
- 全语料总体覆盖文本、图像和表格，不强制每篇同时具备三种模态；
- 覆盖地质图、剖面图、统计图、属性表、地层表等主要类型；
- 按文档划分，不能把同一篇文档的不同Chunk分到开发集和测试集。

你当前已经处理的文档可以作为开发集样本，但不要同时作为最终测试集。

### 2. 标注规模

从16篇文档中按固定种子分层抽取：

| 模态 | 数量 |
|---|---:|
| 文本Chunk | 60 |
| 图像Chunk | 30 |
| 表格Chunk | 30 |
| 合计 | 120 |

每个Chunk标注：

- 实体名称、实体类型；
- 关系及方向；
- 重要属性、数值和单位；
- 原始证据位置；
- Schema映射类型。

在同一文档内继续标注跨模态实体簇：

- 哪些文本、图像、表格实体是同一对象；
- 哪些是同名但不同对象；
- 无法确定的标为 `UNCERTAIN`；
- 保留 `(document_id, chunk_id, original_entity_id)`。

人工标注完成后的目标为至少：

- 100组正确融合实体对；
- 100组困难负例；
- 100条人工核验的最终三元组。

当前仓库已提供可复现数据骨架：`eval/dataset_split/manifest.json` 固定文档划分，
`eval/mvp/chunks.jsonl` 保存候选 Chunk，`eval/mvp/samples/` 保存开发集和测试集样本，
`eval/mvp/annotations/` 提供四类标注模板。机器生成的记录统一标记为 `PENDING`，
只有人工填写并复核后的记录才能计入金标数量。

### 3. 标注人员

MVP不必全部双人标注：

- 一名标注者完成全部数据；
- 第二名标注者独立复核20%的Chunk和融合实体对；
- 分歧由地质专业人员仲裁；
- 报告实体类型、关系和融合判断的 Cohen’s κ。

# 二、四部分最小评测

## 1. 单模态抽取

只报告最核心的指标：

| 评测对象 | 主指标 |
|---|---|
| 文本实体 | Precision、Recall、F1 |
| 文本关系 | Precision、Recall、F1 |
| 图像实体 | Precision、Recall、F1 |
| 图像关系 | Precision、Recall、F1 |
| 表格实体 | Precision、Recall、F1 |
| 表格关系 | Precision、Recall、F1 |
| 表格数值 | 数值准确率、单位准确率 |
| 所有模态 | 无证据实体或关系的幻觉率 |

实体使用严格匹配；关系只有头实体、关系类型、尾实体和方向全部正确才算正确。

最小对比：

- B1：通用LLM/VLM直接抽取；
- B2：你的完整方法，包括模态路由、地质Schema和专用抽取流程。

这张表就能证明专用流程是否优于直接调用模型。

## 2. 多模态融合

MVP只需要三个指标：

1. **Pairwise F1**：实体对是否正确判为同一实体；
2. **B³ F1**：最终实体聚类是否正确；
3. **过度融合率**：不同井、不同地层或父子概念被错误合并的比例。

同时报告：

- Text–Image融合F1；
- Text–Table融合F1；
- Image–Table融合F1；
- `UNCERTAIN`比例；
- 关系端点重写准确率；
- 融合后悬空关系数量。

最小对比：

| 方法 | 说明 |
|---|---|
| F0 | 不融合，所有提及视为独立实体 |
| F1 | 规范化名称完全相同才融合 |
| F2 | 你的完整融合方法 |

## 3. 最终图谱质量

从最终图谱中分层抽取100条三元组人工核验。

评价四项即可：

- 严格三元组正确率；
- Schema合法率；
- 来源证据完整率；
- 图谱结构有效率。

其中：

\[
三元组正确率 =
\frac{头实体、关系、尾实体、方向均正确的三元组数}
{抽样三元组总数}
\]

必须自动检查：

- 悬空关系端点为0；
- 每个融合实体均有来源提及；
- 每条融合关系均有证据；
- 原始实体和关系没有无故丢失；
- `UNMAPPED`和冲突项没有被静默删除。

人工核验采用0～2分：

- 0：错误；
- 1：部分正确或证据不足；
- 2：完全正确。

最终报告“完全正确率”和平均得分。

## 4. 下游可用性

构建60道地质问答题：

| 类型 | 数量 |
|---|---:|
| 单跳事实问答 | 15 |
| 跨模态问答 | 15 |
| 多跳推理 | 10 |
| 表格数值问答 | 10 |
| 综合归纳问答 | 5 |
| 不可回答问题 | 5 |

每题标注标准答案和支持答案的Chunk。

最小对比三个系统：

| 系统 | 外部知识 |
|---|---|
| D0 | 无外部知识，模型直接回答 |
| D1 | 文本向量RAG |
| D2 | 你的多模态融合图谱RAG |

核心指标：

- 答案正确率；
- Evidence Recall@5；
- 证据忠实度；
- 幻觉率；
- 不可回答问题的正确拒答率。

短答案采用Exact Match或人工判断；开放答案按0～2分评价正确性和证据忠实性。

# 三、MVP消融实验

不需要进行十几个消融，做下面三个就够了。

| 消融实验 | 对比设置 | 证明内容 |
|---|---|---|
| A1：Schema消融 | 完整方法 vs 去除Schema约束 | Schema是否改善实体类型和关系抽取 |
| A2：融合消融 | 完整融合 vs 仅名称相同融合 | 上下文、属性、结构和硬约束是否有效 |
| A3：模态消融 | Text-only vs Text+Image+Table | 图像和表格是否带来实际增益 |

A3需要同时观察：

- 新增正确实体数；
- 新增正确关系数；
- 最终三元组正确率；
- 下游问答正确率变化。

如果时间允许，再增加一个：

- A4：去除簇级硬约束，观察过度融合率是否上升。

# 五、MVP验收标准

建议提前规定最低通过线：

| 阶段 | 建议目标 |
|---|---:|
| 单模态实体Macro-F1 | ≥0.75 |
| 单模态关系Macro-F1 | ≥0.65 |
| 实体融合B³ F1 | ≥0.80 |
| 过度融合率 | ≤5% |
| 最终三元组正确率 | ≥85% |
| 来源证据完整率 | 100% |
| 悬空关系端点 | 0 |
| 图谱RAG相对文本RAG | 答案正确率有明确正增益 |
| 不可回答问题幻觉率 | 低于无图谱方法 |

这些是建议目标，不应为了达标调整测试集。

# 六、最低执行顺序

1. 选定16篇文档并冻结开发集、测试集；
2. 制定一页标注规范；
3. 完成120个Chunk的实体和关系标注；
4. 完成跨模态实体簇标注；
5. 构建60道问答题；
6. 运行两个抽取方法、三个融合方法和三个下游系统；
7. 完成三个核心消融；
8. 输出四张主表和典型错误案例。

整个MVP预计需要：

- 数据筛选：1～2天；
- 人工标注：5～7天；
- 实验运行：2～3天；
- 核验与结果整理：2～3天。

因此，**最小可实行版本大约需要12～15天**。它已经能够完整回答四个核心问题：抽取得准不准、融合得对不对、最终图谱可信不可信、图谱对下游有没有用。
