# Chunk 抽取答案格式

文本、图像、表格 Chunk 使用相同格式。每个 Chunk 对应一条记录，`sample_id` 必须与输入一致。实体只写实体名称，关系用“头实体、关系、尾实体”三元组表示。

```json
[
  {
    "sample_id": "File1039::0:text:2",
    "modality": "text",
    "entities": ["延长组", "湖泊三角洲沉积"],
    "relations": [
      ["延长组", "发育", "湖泊三角洲沉积"]
    ]
  }
]
```

`modality` 填 `text`、`image` 或 `table`。没有抽取结果时，`entities` 或 `relations` 填空数组 `[]`。请使用英文双引号和方括号，不要使用中文标点或末尾多余逗号，以保证 JSON 可解析。
